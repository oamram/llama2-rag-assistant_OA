# 🦙 Llama2 Research Assistant (Hybrid LLM Solution)

This repository contains a **hybrid LLM solution** that integrates a fine-tuned **Llama2 model** with a **Retrieval-Augmented Generation (RAG)** system to create an interactive research assistant. The system can answer detailed questions about the Llama2 research paper by combining document retrieval with domain-specific generative capabilities.
